# 📊 Bank Marketing Campaign Analysis & Term Deposit Subscription Prediction

## 📌 Project Overview

This project analyzes the **Bank Marketing Campaign** dataset to identify the factors that influence customers to subscribe to term deposits. Using Python, the project performs data preprocessing, feature engineering, exploratory data analysis (EDA), statistical analysis, and visualization to uncover customer behavior and campaign performance.

## 🎯 Objectives

* Analyze customer demographics and financial factors affecting subscriptions.
* Evaluate the effectiveness of marketing campaigns.
* Identify key features influencing term deposit subscriptions.
* Generate business insights and recommendations for better campaign targeting.

## 📂 Dataset

* **Source:** UCI Machine Learning Repository
* **Domain:** Banking & Direct Marketing
* **Records:** Bank marketing campaign data collected from a Portuguese banking institution.

### Exploratory Data Analysis

* **Univariate Analysis:** Subscription, Balance, Call Duration
* **Bivariate Analysis:** Age Group, Occupation, Balance, Housing Loan, and Call Duration vs Subscription
* **Multivariate Analysis:** Pair Plot and Heatmap

## 📈 Key Insights

* Most customers belong to the middle-age group.
* The dataset is highly imbalanced, with fewer subscribers than non-subscribers.
* Longer call durations are associated with higher subscription rates.
* Customers with higher account balances are more likely to subscribe.
* Customers without housing loans show higher subscription rates.
* Age, occupation, balance, housing loan status, and call duration are key factors influencing subscription.
